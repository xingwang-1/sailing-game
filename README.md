# 帆船游戏｜海风计时赛

一个独立的 3D 帆船计时赛小游戏，画面参考 [Saltwind 3D Sailing Regatta](https://cdn.openai.com/ctf-cdn/sites/saltwind-game-1-1/index.html)。海面、帆船、浮标和群岛由 Three.js 几何体与着色器实时绘制，无需额外图片素材。

## 功能

- 阳光海面、波浪高光、程序化帆船和远景群岛
- 七道浮标门的连续计时竞速
- 航速、风速和竞速状态 HUD
- 阵风加速与冷却时间
- 本地保存个人最佳成绩
- 桌面键盘、鼠标控件与手机触屏转向

## 本地运行

需要 Node.js 20.19 或更新版本。

1. 在本目录运行 `npm install` 安装依赖。
2. 运行 `npm run dev` 启动本地开发服务器。
3. 打开终端显示的地址开始游戏。

运行 `npm run build` 可生成生产版本到 `dist/`。

## 操作

| 操作 | 控制 |
| --- | --- |
| 转向 | A / D 或 ← / → |
| 阵风加速 | 空格或点击 GUST |
| 调整镜头距离 | 右下角 + / − |
| 重新开始 | R |
| 移动端转向 | 屏幕左下角方向按钮 |

依次穿过七道浮标门完成比赛。最佳时间保存在当前浏览器的 localStorage 中。

## 目录结构

- `index.html`：游戏页面与界面结构
- `src/main.js`：Three.js 场景、船体、赛道和竞速逻辑
- `src/style.css`：首页、HUD、对话框及响应式布局
